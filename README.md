# BMI Calculator

## Objective
This project calculates the Body Mass Index (BMI) based on the user's weight and height.

## Features
- Accepts weight in kilograms
- Accepts height in meters
- Calculates BMI
- Displays BMI up to 2 decimal places
- Classifies BMI into:
  - Underweight
  - Normal Weight
  - Overweight
  - Obese
- Handles invalid and negative input

## Technologies Used
- Python 3

## How to Run
1. Open the project in VS Code.
2. Run `bmi_calculator.py`.
3. Enter your weight (kg).
4. Enter your height (m).
5. View your BMI and category.
